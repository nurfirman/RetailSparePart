### Install Command:
```bash
npx skills add vercel-labs/agent-skills@vercel-react-best-practices -g -y
npx skills add supabase/agent-skills@supabase -g -y
npx skills add supabase/agent-skills@supabase-postgres-best-practices -g -y
npx skills add anthropics/skills@frontend-design -g -y
npx skills add vercel-labs/agent-skills@vercel-composition-patterns -g -y
```

## 💡 Rekomendasi Install Prioritas

Untuk fullstack development dengan project ini, saya **paling merekomendasikan** 5 skills di Tier 1:

```bash
# Satu command untuk install semua Tier 1
npx skills add vercel-labs/agent-skills@vercel-react-best-practices -g -y && npx skills add supabase/agent-skills@supabase -g -y && npx skills add supabase/agent-skills@supabase-postgres-best-practices -g -y && npx skills add anthropics/skills@frontend-design -g -y && npx skills add vercel-labs/agent-skills@vercel-composition-patterns -g -y
```

> [!TIP]
> Skills dari **vercel-labs**, **supabase**, dan **anthropics** adalah official sources dengan ratusan ribu installs — sangat terpercaya dan relevan dengan tech stack Anda.

> [!NOTE]
> Skill `neon` dan `neon-postgres` sudah terinstall, jadi integrasi database Neon sudah tercakup.
